# Performance Discussion Form Dashboard

Static case-study page served as part of the main portfolio website.

## Files
- `index.html`: page content and layout
- `style.css`: typography, colors, spacing, and responsive styles
- `pdf-image02/`: all 16 high-resolution images used in 18 placements

## Preview and edit
Run the portfolio from `home-page/`, then open
`/performance-discussion-form/index.html`. Edit content in `index.html` and
styling in `style.css`. Keep the image and media folders beside these files.

The page uses root-relative links for shared homepage navigation and images, so
it must remain inside the homepage's `public/` directory.

The separate Figma interactive prototype remains in Figma; this export contains the website and its images.
