# Performance Discussion Form Dashboard

Static case-study page served as part of the main portfolio website.

## Files

- `index.html`: page content and layout
- `case-study.css`: project-specific typography, spacing, and responsive styles
- `images/`: high-resolution case-study images
- `media/`: the seven GIF demonstrations referenced by the page

## Preview and edit

Run the portfolio from `home-page/`, then open
`/performance-discussion-form/index.html`. Edit content in `index.html` and
styling in `case-study.css`. Keep the image and media folders beside these files.

Only media used by the site belongs in this published folder. Keep original
recordings, alternate exports, and unused posters outside the repository.
The status-workflow GIF in `half-speed-original-colors/` changes frame delays
only, preserving the original image data and colors.

The page loads shared navigation, footer, contact content, and design tokens from
the parent `public/` directory, so it must remain there.

The separate Figma interactive prototype remains in Figma; this export contains the website and its images.
